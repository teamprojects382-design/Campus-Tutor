# Development workflow

1. Create or switch to a feature branch.
2. Implement the smallest change needed to satisfy the task.
3. Run typecheck, lint, and tests before opening a review.
4. Review security considerations and validation errors before merging.
5. Update project documentation when behavior changes.

## Conventional commits
Use commit messages in the form:

- `feat: add study-space scoping`
- `fix: correct env validation message`
- `docs: add migration guide`
- `chore: initialize next.js project`
